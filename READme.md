# 🚗 Smart Immat - Backend

## 📌 Description

Le backend de Smart Immat est une API développée avec Express.js.
Il permet de gérer la logique serveur de l’application, notamment :

La préparation et le suivi des dossiers d’immatriculation.

La gestion des utilisateurs.

La mise à disposition d’outils liés aux fichiers (compression, conversion, etc.).

Ce backend communique avec le frontend React via une API REST.

## ⚙️ Technologies utilisées

- Node.js
- Express.js
- Multer
 (upload de fichiers)
- Sharp (compression et conversion d’images)
- pdf-lib
 (manipulation de PDF : fusion, génération, etc.)
- Cors
 (sécurité des requêtes HTTP)
- Dotenv
 (gestion des variables d’environnement)
